# Animations

Live: https://marcelkempers96.github.io/Animations/

- `index.html` / `reef.html`: Reef Support ASCII ocean, five scenes rendered as 3D ASCII: a coral reef, a dolphin pod, a hunting reef shark in seagrass, a green turtle and a manta ray. Scene switch and a detail slider at the bottom.
- `dolphin.html`, `shark.html`, `lantern-jelly.html`: earlier single-animal versions.
- `docs/`: stand-alone copies of each page.
