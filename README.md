# Animations

- `lantern-jelly.html`: a jellyfish pulsing through a kelp forest, rendered as 3D ASCII in a single self-contained page.
- `dolphin.html`: a bottlenose dolphin swimming laps over a reef and leaping through the surface, rendered as 3D ASCII.
- `shark.html`: blacktip reef sharks cruising over a reef, rendered as 3D ASCII.
- `reef.html`: dolphins and reef sharks in one page, with an animal switch and a detail slider.
